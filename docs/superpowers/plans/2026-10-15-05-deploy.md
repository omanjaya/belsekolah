# Bel Sekolah — Rencana 5: Deploy ke Mini PC Debian Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Satu paket rilis (`belsekolah-<versi>-linux-<arch>.tar.gz`) yang dipasang di mini PC Debian 13 dengan satu perintah `sudo ./install.sh`, menghasilkan layanan systemd yang aman, otomatis jalan, jam tersinkron, `bel.local` aktif, TTS siap, dan panduan pemasangan berbahasa Indonesia untuk operator sekolah.

**Architecture:** `scripts/rilis.sh` membangun frontend + binary statis (amd64 & arm64) dan mengemas bersama `deploy/install.sh`, `deploy/belsekolah.service`, dan `PANDUAN-INSTAL.md`. `install.sh` idempoten (pemasangan pertama = pembaruan). Pemilihan perangkat audio lewat variabel lingkungan `BELSEKOLAH_MPV_DEVICE` (drop-in systemd). Skrip instal diuji di container `debian:trixie` dengan mode uji yang melewati perintah systemd.

**Tech Stack:** Bash, systemd, Debian 13 (apt, pipx, avahi, chrony, unattended-upgrades, alsa-utils), Docker untuk uji, shellcheck.

**Spec:** `docs/superpowers/specs/2026-10-15-bel-sekolah-design.md` §3, §10, §13

## Global Constraints

- Target: Debian 13 (trixie), amd64 utama, arm64 didukung.
- Layanan berjalan sebagai user sistem `belsekolah` (grup `audio`), data di `/var/lib/belsekolah`, binary di `/usr/local/bin/belsekolah`, web di port 80 lewat `CAP_NET_BIND_SERVICE` (bukan root).
- `Restart=always`, `RestartSec=2` (exit code 3 setelah restore ikut dimulai ulang).
- `edge-tts` dipasang lewat pipx ke `/opt/pipx` dengan binary di `/usr/local/bin` (ada di PATH systemd).
- Zona waktu default `Asia/Jakarta`, bisa diganti `--tz`.
- `unattended-upgrades` aktif **tanpa** reboot otomatis.
- Semua pesan skrip dan panduan berbahasa Indonesia.
- Password awal tidak pernah dicetak oleh skrip; skrip menunjukkan perintah `sudo cat /var/lib/belsekolah/password-awal.txt`.
- Skrip lolos `shellcheck` tanpa peringatan.

```go
// EnvDevice memilih perangkat keluaran mpv, mis. "alsa/plughw:CARD=PCH,DEV=0"
// (lihat `mpv --audio-device=help`). Kosong = perangkat default.
const EnvDevice = "BELSEKOLAH_MPV_DEVICE"

func argumenMpv(file string, volume int, ao, device string) []string {
	arg := []string{"--no-config", "--no-video", "--no-terminal", "--really-quiet",
		fmt.Sprintf("--volume=%d", volume)}
	if ao != "" {
		arg = append(arg, "--ao="+ao)
	}
	if device != "" {
		arg = append(arg, "--audio-device="+device)
	}
	return append(arg, "--", file)
}
```

```ini
[Unit]
Description=Bel Sekolah otomatis

EnvironmentFile=-/etc/default/belsekolah
ExecStart=/usr/local/bin/belsekolah -data /var/lib/belsekolah -addr :80 -tz ${BELSEKOLAH_TZ}

# Port 80 tanpa root.
AmbientCapabilities=CAP_NET_BIND_SERVICE
CapabilityBoundingSet=CAP_NET_BIND_SERVICE
NoNewPrivileges=true

# Pengerasan: hanya folder data yang boleh ditulis.
ProtectSystem=strict

ProtectHome=true
PrivateTmp=true
ProtectKernelTunables=true
ProtectKernelModules=true
ProtectControlGroups=true

[Install]
WantedBy=multi-user.target
```

- [ ] **Step 4: `deploy/install.sh`**

```bash
#!/usr/bin/env bash
# Pemasang Bel Sekolah untuk Debian 13. Jalankan dari folder hasil ekstrak paket rilis:
#   sudo ./install.sh [--tz Asia/Jakarta] [--hostname bel] [--perangkat-audio NAMA]
# Aman dijalankan ulang: pemasangan berikutnya memperbarui binary dan konfigurasi.
set -euo pipefail

TZ_SEKOLAH="Asia/Jakarta"
NAMA_HOST="bel"
PERANGKAT_AUDIO=""
UJI="${BELSEKOLAH_UJI:-0}"
DIR="$(cd "$(dirname "$0")" && pwd)"

pesan() { printf '\n==> %s\n' "$*"; }
gagal() { printf '\nGAGAL: %s\n' "$*" >&2; exit 1; }

while [[ $# -gt 0 ]]; do
  case "$1" in
    --tz) TZ_SEKOLAH="${2:?zona waktu kosong}"; shift 2 ;;
    --hostname) NAMA_HOST="${2:?hostname kosong}"; shift 2 ;;
    --perangkat-audio) PERANGKAT_AUDIO="${2:?perangkat audio kosong}"; shift 2 ;;
    -h|--help) sed -n '2,4p' "$0"; exit 0 ;;
    *) gagal "opsi tidak dikenal: $1" ;;
  esac
done

[[ $EUID -eq 0 ]] || gagal "jalankan dengan sudo"
[[ -r /etc/os-release ]] && . /etc/os-release
[[ "${ID:-}" == "debian" ]] || gagal "skrip ini untuk Debian (terdeteksi: ${ID:-tidak diketahui})"
[[ -e "/usr/share/zoneinfo/$TZ_SEKOLAH" ]] || gagal "zona waktu tidak dikenal: $TZ_SEKOLAH"

case "$(dpkg --print-architecture)" in
  amd64) ARSITEKTUR=amd64 ;;
  arm64) ARSITEKTUR=arm64 ;;
  *) gagal "arsitektur $(dpkg --print-architecture) tidak didukung" ;;
esac
BINARY="$DIR/belsekolah-linux-$ARSITEKTUR"
[[ -x "$BINARY" ]] || gagal "binary $BINARY tidak ditemukan di paket"

jalankan() {
  # Di mode uji (container tanpa systemd) perintah sistem dilewati.
  if [[ "$UJI" == "1" ]]; then printf '[uji] lewati: %s\n' "$*"; else "$@"; fi
}

pesan "Memasang paket sistem"
export DEBIAN_FRONTEND=noninteractive
apt-get update -q
apt-get install -y -q --no-install-recommends \
  mpv ffmpeg alsa-utils avahi-daemon chrony unattended-upgrades \
  python3 pipx ca-certificates curl

pesan "Memasang edge-tts (suara TTS)"
export PIPX_HOME=/opt/pipx PIPX_BIN_DIR=/usr/local/bin
if pipx list --short 2>/dev/null | grep -q '^edge-tts '; then
  pipx upgrade edge-tts || true
else
  pipx install edge-tts
fi

pesan "Menyiapkan user dan folder data"
if ! id belsekolah >/dev/null 2>&1; then
  useradd --system --home-dir /var/lib/belsekolah --shell /usr/sbin/nologin --user-group belsekolah
fi
usermod -a -G audio belsekolah
install -d -m 0750 -o belsekolah -g belsekolah /var/lib/belsekolah

pesan "Memasang binary dan dokumentasi"
jalankan systemctl stop belsekolah.service 2>/dev/null || true
install -m 0755 "$BINARY" /usr/local/bin/belsekolah
install -d /usr/local/share/doc/belsekolah
install -m 0644 "$DIR/PANDUAN-INSTAL.md" /usr/local/share/doc/belsekolah/PANDUAN-INSTAL.md
install -m 0644 "$DIR/belsekolah.service" /etc/systemd/system/belsekolah.service

{
  echo "# Dibuat oleh install.sh. Ubah lalu: sudo systemctl restart belsekolah"
  echo "BELSEKOLAH_TZ=$TZ_SEKOLAH"
  if [[ -n "$PERANGKAT_AUDIO" ]]; then
    echo "BELSEKOLAH_MPV_DEVICE=$PERANGKAT_AUDIO"
  elif [[ -f /etc/default/belsekolah ]]; then
    grep '^BELSEKOLAH_MPV_DEVICE=' /etc/default/belsekolah || true
  fi
} > /etc/default/belsekolah.baru
mv /etc/default/belsekolah.baru /etc/default/belsekolah

pesan "Mengatur zona waktu, sinkronisasi jam, dan nama perangkat"
jalankan timedatectl set-timezone "$TZ_SEKOLAH"
jalankan systemctl enable --now chrony.service
jalankan hostnamectl set-hostname "$NAMA_HOST"
if ! grep -qE "^127\.0\.1\.1[[:space:]]+$NAMA_HOST\$" /etc/hosts; then
  sed -i '/^127\.0\.1\.1[[:space:]]/d' /etc/hosts
  echo "127.0.1.1	$NAMA_HOST" >> /etc/hosts
fi
jalankan systemctl enable --now avahi-daemon.service

pesan "Mengaktifkan pembaruan keamanan otomatis (tanpa reboot otomatis)"
cat > /etc/apt/apt.conf.d/20auto-upgrades <<'EOF'
APT::Periodic::Update-Package-Lists "1";
APT::Periodic::Unattended-Upgrade "1";
EOF
cat > /etc/apt/apt.conf.d/51belsekolah-tanpa-reboot <<'EOF'
Unattended-Upgrade::Automatic-Reboot "false";
EOF

pesan "Mengatur volume ALSA ke maksimum (volume diatur dari aplikasi)"
jalankan amixer -q sset Master 100% unmute 2>/dev/null || true
jalankan amixer -q sset PCM 100% unmute 2>/dev/null || true
jalankan alsactl store 2>/dev/null || true

pesan "Menjalankan layanan"
jalankan systemctl daemon-reload
jalankan systemctl enable belsekolah.service
jalankan systemctl restart belsekolah.service

if [[ "$UJI" != "1" ]]; then
  for _ in $(seq 1 30); do
    curl -fsS -o /dev/null http://127.0.0.1/api/sesi && break
    sleep 1
  done
  curl -fsS -o /dev/null http://127.0.0.1/api/sesi || gagal "layanan tidak merespons; lihat: journalctl -u belsekolah -n 50"
fi

IP="$(hostname -I 2>/dev/null | awk '{print $1}')"
cat <<EOF

Bel Sekolah terpasang.

  Buka dari HP/laptop di WiFi sekolah:
    http://${IP:-<alamat-ip>}   (atau http://${NAMA_HOST}.local)

  Password admin awal (hanya untuk login pertama):
    sudo cat /var/lib/belsekolah/password-awal.txt

  Perintah berguna:
    sudo systemctl status belsekolah       status layanan
    sudo journalctl -u belsekolah -f       log
    sudo belsekolah -data /var/lib/belsekolah -reset-password   reset password

  Panduan lengkap: /usr/local/share/doc/belsekolah/PANDUAN-INSTAL.md
EOF
```

Catatan untuk `-reset-password` dijalankan sebagai root: file DB dibuat/diubah oleh root. Tambahkan setelahnya di panduan: `sudo chown -R belsekolah:belsekolah /var/lib/belsekolah && sudo systemctl restart belsekolah`. (Lebih baik: jalankan sebagai user layanan — panduan memakai `sudo -u belsekolah belsekolah -data /var/lib/belsekolah -reset-password`; ubah teks di atas menjadi perintah itu.)

`deploy/uji/uji-install.sh`:

```bash
#!/usr/bin/env bash
# Membangun paket uji, menjalankan install.sh dua kali di container Debian 13,
# lalu menjalankan layanan secara manual sebagai user belsekolah dan memeriksa API.
set -euo pipefail
cd "$(dirname "$0")/../.."

ARSITEKTUR="$(docker info --format '{{.Architecture}}')"
case "$ARSITEKTUR" in
  x86_64|amd64) ARSITEKTUR=amd64 ;;
  aarch64|arm64) ARSITEKTUR=arm64 ;;
esac

KERJA="$(mktemp -d)"
trap 'rm -rf "$KERJA"' EXIT
mkdir -p "$KERJA/paket"
CGO_ENABLED=0 GOOS=linux GOARCH="$ARSITEKTUR" go build -trimpath -o "$KERJA/paket/belsekolah-linux-$ARSITEKTUR" ./cmd/belsekolah
cp deploy/install.sh deploy/belsekolah.service "$KERJA/paket/"
cp PANDUAN-INSTAL.md "$KERJA/paket/" 2>/dev/null || echo "# panduan" > "$KERJA/paket/PANDUAN-INSTAL.md"
cp deploy/uji/Dockerfile "$KERJA/"

docker build -q -t belsekolah-uji-instal "$KERJA" >/dev/null
docker run --rm -e BELSEKOLAH_UJI=1 belsekolah-uji-instal bash -euo pipefail -c '
  ./install.sh --tz Asia/Makassar --hostname bel-uji --perangkat-audio "alsa/default"
  ./install.sh --tz Asia/Makassar --hostname bel-uji   # dijalankan ulang: harus aman
  test -x /usr/local/bin/belsekolah
  test -x /usr/local/bin/edge-tts
  edge-tts --help >/dev/null
  id belsekolah | grep -q audio
  test "$(stat -c %U:%a /var/lib/belsekolah)" = "belsekolah:750"
  grep -q "^BELSEKOLAH_TZ=Asia/Makassar$" /etc/default/belsekolah
  grep -q "^BELSEKOLAH_MPV_DEVICE=alsa/default$" /etc/default/belsekolah   # dipertahankan saat diulang
  grep -q "Automatic-Reboot \"false\"" /etc/apt/apt.conf.d/51belsekolah-tanpa-reboot
  test -f /etc/systemd/system/belsekolah.service
  grep -q "^127.0.1.1	bel-uji$" /etc/hosts

  su -s /bin/sh belsekolah -c "BELSEKOLAH_MPV_AO=null belsekolah -data /var/lib/belsekolah -addr 127.0.0.1:8099 -tz Asia/Makassar" &
  for i in $(seq 1 30); do curl -fsS http://127.0.0.1:8099/api/sesi >/dev/null && break; sleep 1; done
  curl -fsS http://127.0.0.1:8099/api/sesi
  test "$(stat -c %a /var/lib/belsekolah/password-awal.txt)" = "600"
  echo
  echo "UJI INSTAL BERHASIL"
'
```


```bash
#!/usr/bin/env bash
# Membangun paket rilis untuk mini PC: dist/belsekolah-<versi>-linux-<arch>.tar.gz
# Pemakaian: ./scripts/rilis.sh [versi]   (default: git describe)
set -euo pipefail
cd "$(dirname "$0")/.."

VERSI="${1:-$(git describe --tags --always --dirty)}"
(cd web && npm ci && npm run build)
go vet ./...
go test ./...

rm -rf dist && mkdir -p dist
for ARSITEKTUR in amd64 arm64; do
  NAMA="belsekolah-$VERSI-linux-$ARSITEKTUR"
  mkdir -p "dist/$NAMA"
  CGO_ENABLED=0 GOOS=linux GOARCH="$ARSITEKTUR" go build -trimpath \
    -ldflags="-s -w -X main.versi=$VERSI" -o "dist/$NAMA/belsekolah-linux-$ARSITEKTUR" ./cmd/belsekolah
  cp deploy/install.sh deploy/belsekolah.service PANDUAN-INSTAL.md "dist/$NAMA/"
  tar -C dist -czf "dist/$NAMA.tar.gz" "$NAMA"
  rm -rf "dist/$NAMA"
done
(cd dist && sha256sum ./*.tar.gz > SHA256SUMS 2>/dev/null || shasum -a 256 ./*.tar.gz > SHA256SUMS)
ls -lh dist
```

- [ ] **Step 2: `PANDUAN-INSTAL.md`**

Panduan operator (bahasa Indonesia, kalimat sederhana, langkah bernomor). Bagian wajib:

1. **Yang dibutuhkan** — mini PC x86 (SSD, RAM ≥ 2 GB), kabel audio 3.5 mm ke input amplifier (AUX/LINE IN), kabel LAN, flashdisk ≥ 4 GB, akses admin router.
2. **Pengaturan BIOS** — aktifkan "Power On after AC Loss / Restore on AC Power Loss: Power On"; matikan sleep/hibernasi; cara masuk BIOS umum (F2/Del/F1/F10).
3. **Pasang Debian 13** — unduh netinst amd64, tulis ke flashdisk (balenaEtcher/Rufus), instal tanpa lingkungan desktop, centang "SSH server" dan "standard system utilities", buat user admin.
4. **IP tetap** — DHCP reservation di router: cari MAC (`ip link`), contoh nilai, lalu reboot.
5. **Pasang aplikasi** — salin paket (`scp belsekolah-*.tar.gz admin@<ip>:`), `tar xzf`, `cd`, `sudo ./install.sh` (opsi `--tz Asia/Makassar` untuk WITA, `Asia/Jayapura` untuk WIT).
6. **Login pertama** — buka `http://<ip>` atau `http://bel.local` (catatan: `.local` sering tidak jalan di Android, pakai IP), ambil password `sudo cat /var/lib/belsekolah/password-awal.txt`, ganti password.
7. **Sambungkan ke amplifier & uji** — colok jack, atur volume amplifier rendah dulu, Beranda → Bunyikan bel; jika tidak bunyi: lihat bagian Pemecahan Masalah.
8. **Atur jadwal** — urutan singkat: Jenis Bel → Jadwal → Libur → Periode.
9. **Backup** — unduh backup tiap awal semester dan simpan di luar mini PC; backup harian otomatis 7 hari di `/var/lib/belsekolah/backup`.
10. **Pembaruan aplikasi** — salin paket baru, ekstrak, `sudo ./install.sh` lagi (data aman).
11. **Pemecahan masalah** —
    - Tidak ada suara: `aplay -l`, `mpv --audio-device=help`, pilih perangkat analog lalu `sudo ./install.sh --perangkat-audio "alsa/plughw:CARD=PCH,DEV=0"` (contoh), `alsamixer` (pastikan tidak mute, tekan M), cek kabel.
    - Jam salah: `timedatectl`, `chronyc tracking`, pastikan internet; peringatan "Jam belum tersinkron" di Beranda.
    - TTS gagal: cek internet, `sudo env PIPX_HOME=/opt/pipx PIPX_BIN_DIR=/usr/local/bin pipx upgrade edge-tts`.
    - Lupa password: `sudo -u belsekolah belsekolah -data /var/lib/belsekolah -reset-password` lalu `sudo systemctl restart belsekolah`.
    - Tidak bisa dibuka dari HP: pastikan WiFi yang sama (bukan WiFi tamu), cek IP, `sudo systemctl status belsekolah`, `sudo journalctl -u belsekolah -n 50`.
    - Listrik padam: mini PC menyala sendiri (BIOS), bel yang terlewat tercatat "terlewat" di Riwayat.
12. **Checklist uji di lokasi** (dari spec §12): cabut listrik lalu nyalakan, cabut LAN (bel tetap bunyi), cek jam, uji dari Android & iPhone, uji bel darurat & hentikan.

Juga ubah teks akhir `install.sh` agar perintah reset memakai `sudo -u belsekolah belsekolah -data /var/lib/belsekolah -reset-password`.
